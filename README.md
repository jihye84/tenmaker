# 10을 만들어 더하기 (tenmaker)

초등학교 1학년 **받아올림이 있는 덧셈**(9+8, 7+6 …)을
교과서의 '10을 만들어 계산하기' 방법으로 연습하는 웹앱입니다.

👉 **바로 쓰기: https://jihye84.github.io/tenmaker/**

## 이렇게 공부해요

1. **어느 수로 10을 만들지 고르기**
   앞의 수(선택 1)나 뒤의 수(선택 2)를 누르거나,
   블록을 끌어 다른 줄의 빈칸으로 옮겨요.
2. **10이 되려면 몇이 더 있어야 하는지 쓰기**
   맞히면 블록이 날아가 10칸을 채워요.
3. **가르고 남은 수 쓰기**
4. **답 쓰기** — 맞히면 별을 받아요.

답을 알면 단계를 건너뛰고 **최종 답 칸에 바로** 써도 돼요.

## 기능

- **연결모형 블록**: 손가락으로 끌어 옮길 수 있어요.
- **가르기 그림**: 교과서처럼 화살표와 빈칸으로 보여 줘요.
- **손글씨 인식**: 칸 안에 손가락으로 숫자를 쓰면 알아봐요(두 자리 수도 가능).
  인터넷 연결 없이 기기 안에서 인식해요.
- **숫자판**: 화면 아래쪽에 있어 아이들 손이 닿기 쉬워요.
- **힌트**: 두 번 틀리면 세어 볼 블록이 깜빡여요.
- **설정(⚙)**
  - 10 만드는 방법: 스스로 고르기 / 선택 1 / 선택 2 / 번갈아
  - 꼭 들어갈 수(9, 8, 7, 6, 5)
  - 문제 직접 내기, 소리 켜기·끄기
- 휴대폰·태블릿·노트북·교실 TV·전자칠판 어느 화면에서도 스크롤 없이 한 화면에 보여요.
- 카카오톡·네이버 등 앱 안에서 열면 기본 브라우저로 다시 열려요
  (아이폰은 'Safari로 열기' 안내가 떠요).

가중치는 `index.html` 안에 들어 있습니다.

  어린이 글씨에서는 더 낮을 수 있어요.
